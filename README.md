# Student Performance Analyzer

## 📌 Overview
This is a beginner Python project that analyzes student performance data.

The program processes a list of students and provides a summary report including:
- total scores
- number of students who passed and failed
- important flags (e.g. failing students, high scorers)
- overall class status

---

## ⚙️ Features
- Calculates total scores for passed and failed students
- Counts how many students passed and failed
- Detects if there are failing students
- Detects if there are high scorers (score >= 90)
- Determines overall class performance status

---

## 🧠 Concepts Used
This project uses the following Python concepts:
- variables and data types
- loops (for loops)
- conditional statements (if / elif / else)
- functions
- return values
- multiple return values
- flags (True/False logic)
